Acciones manuales

Copia de seguridad local

Materias, horario, tareas, simulacros y chat viven en este navegador. Usa el respaldo para pasarlos al celular. Descarga un respaldo antes de limpiar datos o cambiar de equipo.

Configuración web

Opcional. Solo si conseguiste credenciales de Google Cloud. Sin esto la app funciona igual, pero sin Calendar, Drive ni tutor. Pasos en GUIA-PUBLICAR.md.

Llevar EXAEL al celular

Esta misma página ya es tu app móvil: abre esta URL en el navegador del celular y agrégala a la pantalla de inicio (menú ⋮ → Añadir a pantalla de inicio). localStorage no se comparte entre navegadores ni dispositivos, así que usa el respaldo para pasar tus datos.

Acceso y privacidad

La contraseña impide que alguien abra la app y vea tus datos de un vistazo. No cifra la información: quien tenga acceso al navegador de esta computadora podría leerla igual.

Diagnóstico de conexión

Prueba cada servicio uno por uno y te dice exactamente cuál falla y por qué.
Sin ejecutar. Pulsa el botón para revisar el estado real de cada conexión.

Registro de actividad

Las hojas de cálculo se escriben creando una versión nueva con fecha dentro de la carpeta: el conector de Drive no permite reescribir celdas de un archivo existente. El Calendar sí se actualiza sobre el mismo evento.
